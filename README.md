# Nessa Labs Homebrew tap

```sh
brew install nessalabs/tap/reel
```

| Formula | What it is |
| --- | --- |
| `reel` | Turns short `.reel` scripts into explainer videos. [Source](https://github.com/nessalabs/nessa-video) |

Formulae install the prebuilt release binaries and are updated by each
project's release workflow.
